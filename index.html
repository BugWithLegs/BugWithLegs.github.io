Python based OSINT Tool

PyOSINT is a Python-based OSINT toolkit designed to gather and analyze publicly available information from multiple sources. It combines IP tracing, username enumeration, social media reconnaissance, domain intelligence, and other OSINT utilities into a single tool. Built with Python, PyOSINT aims to make reconnaissance workflows faster and more organized while providing a lightweight, extensible foundation for adding new intelligence-gathering modules.

    Encrypto

    Message Encryption Tool

    A privacy-focused message encryption and decryption tool designed with an anonymous, hacker-inspired aesthetic. It allows users to transform readable messages into encrypted ciphertext that cannot be easily understood without the required key, then decrypt them back when authorized. Built for experimenting with secure communication and cryptography, the tool keeps the workflow simple: enter your message, encrypt it, share or store the ciphertext, and decrypt it when needed. The interface takes inspiration from underground terminals, anonymous networks, and cybersecurity culture while keeping the actual experience clean and straightforward.
